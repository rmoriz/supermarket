About Tools

Tools are software that improve Chef's ecosystem. An example of a tool is Cookstyle. Cookstyle is a Ruby gem that analyzes the code of a Chef Infra cookbook. Most tools are open source and available on GitHub.

Add the tools and plugins that you have created to Supermarket to share them with the community.
